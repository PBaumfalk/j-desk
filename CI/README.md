# J-Desk Brand Assets

Enthalten:
- PNG-Icons in 16, 32, 48, 64, 128, 256, 512 und 1024 px
- Light- und Dark-App-Icon
- monochrome Varianten
- Windows-ICO
- Favicons und Apple-Touch-Icon
- SVG-Wrapper
- Web-App-Manifest

Wichtiger Hinweis:
Das vorliegende SVG bettet das freigegebene Rasterlogo ein. Es ist skalierbar als Datei,
aber kein vollständig editierbares Pfad-Vektorlogo. Für Druck, Plotter, Animation oder
präzise Markenproduktion sollte das Zeichen anschließend als echtes Vektor-Master
nachgezeichnet werden.
