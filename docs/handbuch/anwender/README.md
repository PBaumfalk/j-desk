# Teil 1: Arbeiten mit J-DESK

Für Anwältinnen, Anwälte und alle, die mit Akten arbeiten. Technik kommt hier nicht vor.

## Kapitel

1. **[Was ist J-DESK?](was-ist-j-desk.md)** — worum es geht, in fünf Minuten.
2. **[Der erste Schreibtisch](erster-schreibtisch.md)** — die ersten Handgriffe.
3. **[Vertraulichkeit](vertraulichkeit.md)** — interne Notizen und Schwärzungen. **Bitte einmal
   ganz lesen.**

## Der Gedanke dahinter, in drei Sätzen

Sie breiten die Dokumente einer Akte nebeneinander aus wie Papier auf einem Tisch. Sie ziehen
Linien zwischen dem, was behauptet wird, und dem, was es belegt. Am Ende sehen Sie auf einen
Blick, was steht, was strittig ist und was noch fehlt.

## Wenn Sie gerade wenig Zeit haben

Lesen Sie zwei Dinge:

- den Abschnitt **[Die wichtigsten Begriffe](was-ist-j-desk.md#die-wichtigsten-begriffe)** —
  danach verstehen Sie die Oberfläche
- **[Vertraulichkeit](vertraulichkeit.md)** — weil es um Ihre Berufspflichten geht

Alles andere erschließt sich beim Tun.
