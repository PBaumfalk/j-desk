## Drei Dinge, die Sie beruhigen sollten

**1. Sie können nichts kaputt machen.** Es gibt einen Papierkorb, eine vollständige
Historie und automatische Sicherungen. Fast alles lässt sich zurückholen.

**2. In j-lawyer wird nie etwas gelöscht.** Wenn Sie in J-DESK etwas „in den Papierkorb"
legen, verschwindet es nur von diesem Schreibtisch. Das Dokument in j-lawyer bleibt
unangetastet.

**3. Sie müssen nicht speichern.** Es gibt keinen Speichern-Knopf, weil laufend
gespeichert wird. Browser zumachen ist ungefährlich.
