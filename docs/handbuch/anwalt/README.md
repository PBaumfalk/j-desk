## Die 15 häufigsten Fragen

| Was Sie wollen | So geht's |
|---|---|
| **Anmelden** | Ihre **j-lawyer-Zugangsdaten**. → [Kapitel 2](02-erster-schreibtisch.md#anmelden) |
| **Dokumente nebeneinanderlegen** | Karten ziehen; zum Lesen Doppelklick. → [Kapitel 2](02-erster-schreibtisch.md) |
| **Behauptung mit Fundstelle verknüpfen** | Rechtsklick → **Verknüpfen…**, dann Ziel anklicken. → [Kapitel 3](03-verknuepfen.md) |
| **Sagen, *worin* die Beziehung besteht** | Linie anklicken → Bedeutung wählen (belegt, widerspricht …). → [Kapitel 3](03-verknuepfen.md#die-elf-beziehungsarten) |
| **Sehen, wo mein Vortrag Lücken hat** | **Auswertung öffnen** → „Tatsachen ohne Beweismittel". → [Kapitel 4](04-luecken-finden.md) |
| **Prüfen, was ich noch nicht erwidert habe** | Auswertung → „Behauptungen der Gegenseite ohne Erwiderung". → [Kapitel 4](04-luecken-finden.md) |
| **Zurück zur Originalstelle** | Rechtsklick → **Zur Originalstelle** — öffnet das Dokument an der Stelle. → [Kapitel 3](03-verknuepfen.md#jede-fundstelle-bleibt-auffindbar) |
| **Zeitlichen Ablauf darstellen** | Zeitleiste anlegen, Objekte hineinziehen. → [Kapitel 5](05-chronologie-und-vergleich.md) |
| **Zwei Fassungen vergleichen** | Rechtsklick → **Vergleichen mit…** → [Kapitel 5](05-chronologie-und-vergleich.md#zwei-fassungen-vergleichen) |
| **Etwas als streitig markieren** | Verknüpfung mit Bedeutung *streitig* oder *widerspricht*. → [Kapitel 3](03-verknuepfen.md) |
| **Interne Notiz, die niemand sonst sieht** | Notiz anlegen — ist von sich aus **intern**. → [Kapitel 6](06-vertraulichkeit.md) |
| **Schwärzen** | Markieren und schwärzen; der Text wird **entfernt**, nicht übermalt. → [Kapitel 7](07-export-und-schwaerzen.md) |
| **Anlagenkonvolut erzeugen** | Meist macht das das Sekretariat. → [ReFa-Kapitel 3](../refa/03-anlagenpaket.md) |
| **Für den Termin vorbereiten** | Sitzungsmappe anlegen, im Termin Sitzungsmodus. → [Kapitel 8](08-termin-und-ki.md) |
| **KI etwas vorschlagen lassen** | Vorschläge kommen zur Prüfung, nie automatisch in die Akte. → [Kapitel 8](08-termin-und-ki.md#ki) |

## Worum es im Kern geht

J-DESK ist darauf gebaut, jederzeit eine Frage beantworten zu können:

> **Welche Behauptung wird durch welche konkrete Fundstelle belegt, welche Gegenposition
> besteht, was ist noch offen — und welches verwertbare Arbeitsergebnis entsteht daraus?**

Wenn Sie nur eine Sache aus diesem Handbuch mitnehmen: **[Kapitel 3, Verknüpfen](03-verknuepfen.md)**.
Alles andere ist Zubehör.
